## Overview
SurfaceGuard AI aims to detect industrial surface anomalies, classify them into four defect categories, and localize defective pixels using image segmentation.

## Objectives
- Explore the industrial image dataset and defect annotations.
- Decode and visualize run-length encoded (RLE) masks.
- Develop and evaluate segmentation models.
- Track experiments using Weights & Biases.
- Generate valid Kaggle submissions and improve the competition score.

## Repository Structure
- `notebooks/` — Exploration, experiments and inference notebooks.
- `src/` — Preprocessing, training, inference and utility code.
- `scripts/` — Helper scripts and submission utilities.
- `reports/` — Milestone and final reports.
